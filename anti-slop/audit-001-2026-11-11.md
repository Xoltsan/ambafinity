# Anti-Slop UI Audit: AmbaFinity Dashboard & Overlay Suite
**Date**: 2026-11-11  
**Audit File**: `anti-slop/audit-001-2026-11-11.md`  
**Target**: `scripts/tiktok-live-stream/control.html`, `overlay.html`  
**Reference Stack**: IndoFinity (`app.indofinity.com`) via `wappalyzer_app-indofinity.com.csv` (Tailwind CSS, shadcn/ui, Radix UI, Lucide Icons, Plus Jakarta Sans)

---

## Numbered Findings List

### [HIGH] Hard Gate Rules
1. **[R-03] Mobile Responsiveness**: Sidebar navigasi di `control.html` memiliki lebar statis 250px tanpa hamburger drawer untuk layar kecil (< 768px), memicu horizontal overflow dan tap target yang sempit di mobile.
2. **[R-26] Interactive Elements**: Sejumlah kontrol interaktif seperti pilihan preset (`chill-stream`, `gaming-rage`) dan dropdown filter tidak memiliki fungsi state aktif di backend.
3. **[R-27] UI States**: Tabel Pusat Interaksi dan selector asset video belum memiliki state *Loading skeleton* dan *Error state* yang jelas saat fetch API tertunda atau gagal.
4. **[R-32] Keyboard Accessibility**: Modal dialog (`interaction-modal`) belum memiliki focus trap, navigasi Tab tidak mengunci di dalam modal, dan belum bisa ditutup dengan tombol keyboard `Escape`.
5. **[R-39] Accessible Semantics**: Tombol berbasis icon (seperti tombol switch, aksi cepat, dan edit) belum dilengkapi `aria-label` untuk screen reader serta `focus-visible` ring.

---

### [MEDIUM] Purpose-Gate Rules
6. **[R-04] Icons**: Dashboard masih memakai karakter emoji OS (⚡, 🎵, 🧪, 📋, 📊) alih-alih vector **Lucide Icons** resmi seperti yang digunakan pada IndoFinity.
7. **[R-06] Typography**: Hirarki teks dan perbandingan ukuran font masih bervariasi dengan style inline acak, belum terstandarisasi dengan skala tipografi modular shadcn/ui.
8. **[R-10 & R-13] Glassmorphism & Glow**: Terdapat efek glow box-shadow neon dan blur kaca yang bertumpuk tanpa purpose token yang terdefinisi rapi.
9. **[R-11] Border Radius**: Radius sudut elemen tidak seragam (bercampur antara 28px, 14px, 10px, 8px, dan pill 99px) sehingga tidak mencerminkan konsistensi design system modern.

---

### [LOW] Quality Locks
10. **[R-20] Visual Identity & Tech Alignment**: Arsitektur styling masih berupa CSS raw inline ratusan baris, belum mengadopsi utilitas **Tailwind CSS** dan tema dark mode terstruktur ala **shadcn/ui** (seperti yang terdeteksi pada IndoFinity).
11. **[R-29] Color Palette**: Penggunaan warna masih tersebar dengan kode hex arbitrer (`#f43f5e`, `#ec4899`, `#8b5cf6`, `#3b82f6`, `#facc15`, `#10b981`), perlu distandarkan ke semantic color tokens (`primary`, `muted`, `card`, `border`, `accent`, `destructive`).
12. **[R-31] Design Decision Purpose**: Spasi antar section dan struktur grid belum memiliki dokumentasi alasan fungsional yang eksplisit per komponen.
